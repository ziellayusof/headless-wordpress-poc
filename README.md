# Git Repository POC

## Purpose

This project is a simple Proof of Concept (POC)
to demonstrate Git Repository and version control
for web development.

## Project

A simple HTML webpage is used to demonstrate:

- Git repository initialization
- Version control
- Commit history
- Branching
- Merging
- GitHub remote repository

## Files

- index.html - Simple web page
- README.md - Project documentation
- .gitignore - Files excluded from Git
